# Building with the Claude API

Notebooks from the course of the same name. Each one isolates a single concept, built on the same
`add_user_message` / `add_assistant_message` / `chat` helpers.

## Setup

```bash
pip install anthropic python-dotenv jupyter
```

Put your key in a `.env` here — every notebook calls `load_dotenv()`, so `Anthropic()` picks it up:

```
ANTHROPIC_API_KEY=your-key-here
```

## Notebooks

In the order the concepts build:

| Notebook | Concept |
| --- | --- |
| `multiturn-conversations.ipynb` | The messages list — the API is stateless, you resend the whole conversation each turn. |
| `chat-exercise.ipynb` | Same thing wrapped in a REPL loop. |
| `system-prompts.ipynb` | `system` for persona and style, separate from the conversation. |
| `temperature.ipynb` | The creativity dial (1.0 varied, 0.0 focused). |
| `response-streaming.ipynb` | Raw `stream=True` events vs. the SDK's `messages.stream()` helper. |
| `structured-data.ipynb` | Parseable output via message prefilling + `stop_sequences`. |
| `prompt-evals.ipynb` | **Unfinished** — dataset generation works, the eval itself isn't built out. |

`dataset.json` is generated by `prompt-evals.ipynb`: three AWS coding tasks used as eval inputs.

The model is set per notebook, so they don't all use the same one — change the `model` variable at the top to switch.
